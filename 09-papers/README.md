# 深度学习经典论文阅读

本目录收录深度学习领域的经典论文,按主题分类,每篇论文包含导读说明、核心思想、关键贡献和个人笔记。

## 阅读方法

1. **先读导读**: 了解论文背景、解决的问题和主要贡献
2. **再读摘要和结论**: 把握论文核心思想
3. **深入方法部分**: 理解技术细节
4. **做笔记**: 记录关键点和思考
5. **跑代码**: 如有开源实现,动手实践

## 论文分类

### 01-foundation - 深度学习基础
深度学习奠基性工作,理解神经网络的基本原理

### 02-cnn - 卷积神经网络
计算机视觉领域的经典CNN架构

### 03-rnn - 循环神经网络
序列建模和RNN变体

### 04-transformer - Transformer架构
注意力机制和Transformer系列

### 05-llm - 大语言模型
预训练语言模型和LLM技术

### 06-training - 训练技术
优化、正则化等训练方法

### 07-generative - 生成模型
GAN、VAE、扩散模型等

### 08-reinforcement - 强化学习
深度强化学习经典工作

## 学习建议

### 阅读顺序
1. **基础优先**: 先读训练技术论文(Adam, BN, Dropout)
2. **架构演进**: CNN(AlexNet→VGG→ResNet)→Transformer→LLM
3. **结合实践**: 读论文同时跑代码

### 笔记模板
每篇论文建议记录:
- **一句话总结**: 用一句话概括论文核心贡献
- **关键创新**: 相比之前工作的主要改进
- **技术细节**: 重要的公式、算法、架构图
- **实验结果**: 主要实验结论
- **个人思考**: 启发、疑问、延伸想法
- **相关论文**: 引用的重要工作、后续发展
