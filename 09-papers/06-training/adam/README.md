# Adam: A Method for Stochastic Optimization

## 论文信息

- **标题**: Adam: A Method for Stochastic Optimization
- **作者**: Diederik P Kingma, Jimmy Ba (University of Toronto)
- **发表**: ICLR 2015
- **链接**: [Paper](https://arxiv.org/abs/1412.6980) | [Code](https://github.com/pytorch/pytorch/blob/main/torch/optim/adam.py)

## 一句话总结

Adam结合了Momentum和RMSProp的优点,为每个参数自适应调整学习率,成为深度学习最常用、最通用的优化算法。

## 历史背景

### 优化算法的演进

**SGD (随机梯度下降)**:
- 最简单,最基础
- 收敛慢,容易震荡
- 需要仔细调学习率

**Momentum (1964, Qian 1999)**:
- 累积动量加速收敛
- 帮助逃离局部最优
- 减少震荡

**AdaGrad (2011)**:
- 自适应学习率
- 对稀疏梯度效果好
- 但学习率单调递减,可能过早停止

**RMSProp (2012)**:
- 改进AdaGrad
- 使用移动平均
- 解决学习率递减问题

**Adam (2014)**:
- 结合Momentum + RMSProp
- 偏差修正
- 成为默认选择

### 为什么需要自适应学习率?

**不同参数需要不同学习率**:
- 稀疏特征: 需要更大更新
- 稠密特征: 需要更小更新
- 梯度变化大的参数: 需要谨慎更新

**手动调参困难**:
- 每个参数单独调不现实
- 训练过程中需求会变化
- 需要自动适应

## 核心创新

### 1. 算法设计

Adam维护两个移动平均:

**一阶矩估计 (均值, Momentum)**:
```
m_t = β₁ * m_{t-1} + (1 - β₁) * g_t
```
- 累积梯度历史
- 提供动量加速

**二阶矩估计 (未中心化方差, Adaptive Learning Rate)**:
```
v_t = β₂ * v_{t-1} + (1 - β₂) * g_t²
```
- 累积梯度平方
- 衡量梯度变化幅度

**偏差修正** (关键创新):
```
m̂_t = m_t / (1 - β₁^t)
v̂_t = v_t / (1 - β₂^t)
```
- 解决初始化偏差
- 初期估计更准确

**参数更新**:
```
θ_t = θ_{t-1} - α * m̂_t / (√v̂_t + ε)
```

### 2. 直观理解

**物理类比**:
- 一阶矩: 速度 (Velocity)
- 二阶矩: 惯性/质量 (Mass)
- 更新步长: 速度 / √惯性

**几何解释**:
- 梯度大的方向: 步长小(谨慎)
- 梯度小的方向: 步长大(加速)
- 一致梯度方向: 加速
- 震荡梯度方向: 减速

### 3. 超参数设计

**默认推荐值**:
- α (学习率): 0.001
- β₁ (一阶衰减): 0.9
- β₂ (二阶衰减): 0.999
- ε (数值稳定): 10^-8

**为什么这样设计?**
- β₁=0.9: 约10个梯度历史
- β₂=0.999: 约1000个梯度平方历史
- ε: 防止除零

## 算法伪代码

```
初始化:
  m_0 = 0 (一阶矩向量)
  v_0 = 0 (二阶矩向量)
  t = 0 (时间步)

对于每个迭代 t:
  t = t + 1
  g_t = ∇_θ f_t(θ_{t-1})  (计算梯度)
  
  m_t = β₁ * m_{t-1} + (1 - β₁) * g_t      (更新一阶矩)
  v_t = β₂ * v_{t-1} + (1 - β₂) * g_t²     (更新二阶矩)
  
  m̂_t = m_t / (1 - β₁^t)                   (偏差修正)
  v̂_t = v_t / (1 - β₂^t)                   (偏差修正)
  
  θ_t = θ_{t-1} - α * m̂_t / (√v̂_t + ε)    (更新参数)
```

## 理论性质

### 收敛性保证

**凸优化**:
- 遗憾界(Regret Bound): O(√T)
- 与Adagrad相当

**非凸优化** (深度学习常见):
- 收敛到局部最优
- 实践中表现优异

### 优势分析

**1. 计算高效**:
- 时间和空间复杂度O(d), d为参数数量
- 只需一阶梯度
- 实现简单

**2. 内存需求小**:
- 只需存储m和v两个向量
- 与参数同维度

**3. 适合大规模数据**:
- 逐样本或小批量更新
- 适合在线学习

**4. 超参数鲁棒**:
- 默认参数在多数场景有效
- 对学习率不那么敏感

## 实验验证

### 测试任务

**1. 逻辑回归**:
- MNIST分类
- 收敛速度比SGD快

**2. 全连接神经网络**:
- 多层感知机
- 在各种数据集上稳定

**3. 卷积神经网络**:
- CIFAR-10图像分类
- 与SGD+Momentum相当或更好

**4. 循环神经网络**:
- 语言建模
- 显著优于其他方法

### 关键发现

**学习率敏感性**:
- Adam对学习率选择更鲁棒
- SGD需要更仔细调参

**不同架构表现**:
- CNN: Adam ≈ SGD+Momentum
- RNN: Adam > 其他方法
- Transformer: Adam是标准选择

**收敛速度**:
- 前期收敛快
- 后期可能不如调好的SGD

## 局限性和改进

### 1. 泛化问题

**发现**:
- Adam训练损失下降快
- 但测试集性能有时不如SGD
- 可能收敛到更宽的极小值

**原因分析**:
- 自适应学习率可能"走捷径"
- L2正则化与权重衰减不等价

**解决方案**:
- **AdamW**: 解耦权重衰减
- 使用学习率衰减
- 后期切换到SGD

### 2. 二阶矩偏差

**问题**:
- 二阶矩估计可能不准确
- 特别是稀疏梯度

**改进**:
- **AMSGrad**: 使用最大二阶矩
- **AdaBound**: 限制学习率范围

### 3. 内存占用

**问题**:
- 需要存储m和v
- 大模型内存压力大

**改进**:
- **8-bit Adam**: 量化优化器状态
- **Adafactor**: 分解二阶矩

## 变体和改进

### AdamW (2017)

**核心改进**:
- 正确的权重衰减实现
- L2正则化 → 权重衰减

**公式对比**:
```
# Adam + L2 (错误)
θ_t = θ_{t-1} - α * (m̂_t / (√v̂_t + ε) + λθ_{t-1})

# AdamW (正确)
θ_t = θ_{t-1} - α * m̂_t / (√v̂_t + ε) - αλθ_{t-1}
```

**效果**:
- 更好的泛化
- 现在成为标准实现

### AMSGrad (2018)

**动机**:
- 解决Adam可能不收敛的问题
- 保证收敛性

**改进**:
```
v̂_t = max(v̂_{t-1}, v_t)  # 使用最大值
```

**实际效果**:
- 理论保证好
- 实践中不一定比Adam好

### RAdam (2019)

**动机**:
- Adam初期方差大
- 需要预热(warmup)

**改进**:
- 自适应预热
- 根据方差大小调整学习率

**效果**:
- 不需要手动预热
- 训练更稳定

### AdaBound (2019)

**动机**:
- Adam和SGD的折中

**改进**:
- 限制学习率范围 [η_l, η_u]
- 随着训练,逐渐接近SGD

## 实践建议

### 何时使用Adam?

**推荐使用**:
- 快速原型验证
- 小数据集
- RNN/LSTM/Transformer
- 稀疏梯度场景
- 不想调参时

**考虑SGD**:
- 追求最终精度
- 大数据集
- CNN图像任务
- 有足够时间调参

### 超参数调优

**学习率**:
- 默认: 0.001
- 常见范围: 0.0001 - 0.01
- 使用学习率调度

**β₁和β₂**:
- 通常保持默认
- 如果梯度噪声大,减小β₁

**ε**:
- 默认1e-8足够
- 半精度训练时增大到1e-4

### 代码示例 (PyTorch)

```python
import torch
import torch.nn as nn

# 定义模型
model = nn.Linear(10, 1)

# Adam优化器
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001,           # 学习率
    betas=(0.9, 0.999), # β₁, β₂
    eps=1e-8,           # ε
    weight_decay=0      # L2正则化(AdamW中才是正确的权重衰减)
)

# AdamW (推荐)
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=0.001,
    weight_decay=0.01   # 正确的权重衰减
)

# 训练循环
for epoch in range(num_epochs):
    for data, target in dataloader:
        optimizer.zero_grad()
        output = model(data)
        loss = criterion(output, target)
        loss.backward()
        optimizer.step()
```

## 个人思考

### 为什么Adam如此成功?

1. **简单有效**:
   - 算法简单,易于实现
   - 默认参数效果好
   - 理论保证和实践效果兼具

2. **通用性强**:
   - 适用于各种架构
   - 各种任务都表现不错
   - 不同领域都接受

3. **工程友好**:
   - 计算高效
   - 内存需求合理
   - 易于并行

### 使用Adam的注意事项

1. **不是万能的**:
   - 有些任务SGD更好
   - 需要尝试对比

2. **泛化问题**:
   - 配合权重衰减
   - 使用学习率衰减
   - 考虑后期切换到SGD

3. **超参数仍重要**:
   - 学习率调优仍有收益
   - 不要完全依赖默认参数
